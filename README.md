# 경북대학교 도서관 이용 가이드

경북대학교 도서관은 1952년 개관하여, 현재 약 350만 권의 장서를 보유한 국립 대학교입니다. 본 저장소는 경북대학교 도서관의 주요 시설, 서비스 및 이용 정보를 체계적으로 정리하였습니다.

## 비전 및 전략

- 거침없는 성장을 위한 학술정보자원
- 지식 접근성을 확장하는 교육·연구 지원 서비스
- 더 큰 세계를 준비하는 대학도서관

## 목표

- 세계적 수준의 전략적 전자지원 확보
- 이용자 친화적 도서관 환경
- 기초소양 및 학습지원 강화
- 연구 활동 지원 서비스 확대
- 직원 전문성 강화
- 스마트 서비스 고도화

## 실행계획

- 전략적 전자자료 확충 체계
- 학술정보자원 이용 및 활용률 제고
- 미래교육을 위한 시설 환경 개선
- 공간 효율성 제공
- 도서관 정보자원 활용 교육 확대
- 바로지원 서비스
- 연구자 맞춤형 연구지원 서비스
- 최신 연구 동향 큐레이션
- 직무향상 교육 지원
- 전문역량 강화 프로그램 운영
- 디지털 정보 활용 프로그램 개발 운영

## 팀원들과 정한 규칙
### 파일 이름 및 형식은 팀 내에서 정한 기준을 따름
-	md 파일 이름은 통일된 형식 사용
-	문서 제목 및 구조는 README에서 정한 기준에 맞추어 작성함
### 하나의 Commit에는 하나의 작업 내용만 포함하도록 함
- 여러 내용을 한 번에 수정하기보다 작업 단위별로 나누어 commit 진행함
-	변경 사항을 쉽게 확인할 수 있도록 하기 위함
### 작업 전 최신 버전 확인 후 수정 진행
-	다른 팀원의 작업 내용과 충돌을 방지하기 위해 작업 전 최신 상태를 확인함
-	동일한 파일을 동시에 수정하는 상황을 최소화하기 위함
